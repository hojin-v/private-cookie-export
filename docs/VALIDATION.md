# 검증 기록

## 0.3.6 · Private Cookie Export

| 검사 | 확인 범위 |
| --- | --- |
| Node 단위 검사 | 22개 통과. 사생활 보호 저장소, 단일 탭, 발신자·동의, 사이트 권한, 호스트·경로 경계, YouTube 저장용 주소에 적용되지 않는 다른 호스트 전용 및 다른 경로 쿠키 제외, 외부 리디렉션 차단, 명시적으로 요청한 저장용 탭 닫기, 한국어·영어 문구 키 일치 |
| Mozilla `addons-linter` | 오류·경고·안내 0개. 개발 의존성은 `npm audit` 기준 알려진 취약점 0개 |
| 데스크톱 Firefox 160.0.1 | 한국어판과 영어판에서 각각 YouTube 자동 전환과 일반 HTTPS 사이트의 팝업을 통해 `cookies.txt` 다운로드를 검증했습니다. YouTube는 `www.youtube.com`에만 호스트 권한을 부여한 상태에서 적용 가능한 `.youtube.com` 공유 쿠키를 저장했습니다. 두 모드 모두 일반 저장소와 다른 경로의 쿠키를 제외했습니다. Firefox의 `connect-src` 강제 차단 이벤트와 팝업 건수 및 탭 닫기 동작도 확인했습니다. |
| RabbYT 가져오기 | Android `main` Java 파서가 새 버전의 합성 YouTube 파일을 받아들였습니다. 인증 구조, HttpOnly, 호스트 범위, 만료 유지 확인 |
| Android Firefox 160.0.1 | 사용자가 0.3.5를 사용해 실제 YouTube 쿠키를 저장하고 RabbYT에 가져와 로그인이 동작한다고 확인했습니다. 0.3.6은 해당 버전의 쿠키 범위와 저장 형식을 유지하고, 저장 이름과 화면 언어를 바꿉니다. |
| 빌드 | 제출용 ZIP·공개용 소스 ZIP·SHA-256 생성 및 현재 소스와 재대조 |

브라우저 검사는 합성 쿠키와 별도 임시 프로필을 씁니다. 테스트 하네스에만 다운로드 완료 확인용 권한이 있습니다. Mozilla 서명 후 일반 설치와 최종 XPI 소스 대조를 수행합니다.

임시 복사본에서 검사 주소를 `connect-src`에 허용하자 동일한 검사가 실패했습니다. 요청 자체가 실패해도 Firefox의 CSP 차단 이벤트가 없으면 통과할 수 없습니다.

## 0.2.0 · 최초 실기기 확인

사용자가 Android Firefox 160.0.1에서 YouTube로 로그인하고 당시 도우미로 저장한 파일을 RabbYT 3.0.2에 가져왔습니다. RabbYT에서 **로그인 정보 저장됨**을 확인했습니다. 이 결과는 0.2.0의 YouTube 경로에 해당합니다.
