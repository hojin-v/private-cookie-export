# cookies.txt에 담기는 것

쿠키는 사이트가 브라우저에 저장하는 이름과 값입니다. 설정을 기억하는 쿠키도 있고, 로그인한 세션을 식별하는 쿠키도 있습니다. 호환 도구가 브라우저와 별도로 접속하면서 사용자가 이미 로그인한 세션을 사용해야 할 때 `cookies.txt`를 가져올 수 있습니다. 로그인 없이 할 수 있는 작업에는 이 파일이 필요하지 않습니다. 파일을 만들어도 세션의 만료나 권한은 사이트가 결정합니다. [HTTP 쿠키 설명](https://curl.se/docs/http-cookies.html)

## 사이트별 범위

초기 자체 도우미는 설치 시 YouTube 호스트 권한을 요청하고 YouTube 경로만 제공했습니다. 범용 버전은 사이트를 사용할 때 Firefox 권한을 요청하며 YouTube 전용 경로와 일반 사이트 경로를 함께 제공합니다.

| 구분 | 포함하는 쿠키 | 페이지 동작 |
| --- | --- | --- |
| 일반 모드 | 승인한 현재 HTTPS 페이지에 적용되는 쿠키. 현재 호스트 전용 쿠키와 현재 주소에 적용되는 상위 도메인 공유 쿠키가 포함될 수 있습니다. 경로도 일치해야 합니다. 로그인 여부를 추정하지 않아 사이트 설정 쿠키도 포함될 수 있습니다. | 페이지를 이동하지 않습니다. |
| YouTube | `youtube.com` 및 하위 도메인의 사생활 보호 쿠키 중 필터를 통과한 항목. `LOGIN_INFO`와 API 세션 관련 쿠키가 있는지 형태만 검사합니다. 이 조건을 만족해도 포함된 모든 항목이 로그인에 필요한 것은 아니며 실제 세션의 유효성을 판정하지 않습니다. | 같은 탭을 `www.youtube.com/robots.txt`로 옮겨 일반 YouTube 페이지에서 발생하는 쿠키 갱신 가능성을 줄입니다. 파일을 저장한 뒤 팝업에서 해당 탭을 닫을 수 있습니다. |

두 모드 모두 사생활 보호 탭 한 개에서 진행합니다. 다른 저장소, 만료된 쿠키, 파티션 또는 First-Party Isolation에 묶인 쿠키는 제외합니다. 브라우저의 기록·입력란·비밀번호 저장소는 읽지 않습니다. [YouTube에서 `robots.txt`를 쓰는 이유](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies)

## 파일의 일곱 열

각 줄은 쿠키 한 개이며 열은 탭 문자로 구분합니다. 아래는 실제 계정에 접근할 수 없는 예시입니다.

```text
# Netscape HTTP Cookie File
#HttpOnly_.example.test	TRUE	/app	TRUE	0	DEMO_SESSION	DEMO_VALUE
```

| 순서 | 항목 | 의미 |
| --- | --- | --- |
| 1 | 도메인 | 쿠키가 적용되는 호스트 또는 도메인입니다. 앞에 `#HttpOnly_`가 있으면 사이트 페이지의 JavaScript가 읽지 못하는 `HttpOnly` 쿠키입니다. |
| 2 | 하위 도메인 포함 | `TRUE`는 하위 도메인에도 적용됩니다. `FALSE`는 해당 호스트 전용입니다. |
| 3 | 경로 | 도메인 안에서 쿠키가 적용되는 주소 경로입니다. `/`는 루트 범위입니다. |
| 4 | Secure | `TRUE`는 쿠키를 HTTPS 연결에만 보내라는 속성입니다. 다운로드 파일 자체는 평문입니다. |
| 5 | 만료 | 초 단위 Unix 시각입니다. `0`은 파일 형식에서 세션 쿠키를 뜻합니다. 세션이 계속 유효하다는 뜻은 아닙니다. |
| 6 | 이름 | 사이트에서 쿠키를 구분하는 키입니다. |
| 7 | 값 | 사이트가 저장한 값입니다. 세션 값이 유효하면 해당 계정으로 접속하는 데 쓰일 수 있어 가장 민감합니다. |

팝업의 **세션**과 **HttpOnly** 건수는 서로 겹칠 수 있습니다. 예시의 쿠키는 두 건수에 모두 포함됩니다. 팝업에는 파일 저장 전에 건수만 표시합니다. `SameSite` 등 Netscape 파일에 열이 없는 브라우저 속성은 파일에 담기지 않습니다. 파일을 가져간 도구가 요청을 보내면 대상 사이트에 쿠키 값이 전달될 수 있으니 신뢰하는 도구에서만 사용하고, 사용이 끝나면 원본을 삭제하세요. [Netscape 형식 설명](https://curl.se/docs/http-cookies.html#cookies-saved-to-disk) · [Firefox 쿠키 속성](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/cookies/Cookie)
