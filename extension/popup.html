RabbYT 로그인 도우미

YouTube 로그인 정보만 이 기기에 저장합니다. 서버로 보내지 않으며, 아이디와 비밀번호를 읽거나 저장하지 않습니다.

탭을 확인하고 있습니다.

처음 사용하나요?
  1. Firefox 확장 기능 설정에서 이 도우미의 ‘사생활 보호 모드에서 실행’을 허용합니다.
  2. 사생활 보호 탭 한 개에서 YouTube 로그인과 추가 인증을 마칩니다. 다른 사생활 보호 탭은 닫아 주세요.
  3. 이 도우미에서 저장 버튼을 누릅니다. 저장용 주소 전환과 탭 닫기는 도우미가 처리합니다.
  4. RabbYT의 열쇠 → YouTube → 로그인 정보 가져오기에서 RabbYT-youtube-login-…txt 파일을 선택합니다.
  5. 가져오기가 성공하면 다운로드한 원본을 삭제하고 도우미를 꺼두어도 됩니다.

이 파일은 비밀번호처럼 보호해 주세요. 직접 만든 도우미라도 계정 만료나 YouTube의 이용 제한 위험까지 없애지는 못합니다.
