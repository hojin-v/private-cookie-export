파일 저장

계정 접근에 사용할 수 있는 평문 파일입니다. 필요한 도구에서 사용한 뒤 지우세요.

사용법
  1. Firefox 확장 설정에서 사생활 보호 모드에서 실행을 허용합니다.
  2. 사생활 보호 탭 한 개에 원하는 HTTPS 페이지를 엽니다. 세션이 필요하면 해당 사이트에서 로그인합니다.
  3. 이 팝업에서 쿠키 파일 준비를 누릅니다. 처음 사용하는 사이트라면 Firefox에서 권한을 승인합니다.
  4. 건수를 확인하고 파일 저장을 누릅니다. YouTube는 다운로드 완료를 확인한 뒤 다운로드 확인 후 탭 닫기를 누릅니다.
파일 내용과 권한

쿠키마다 적용 주소·경로·만료·이름·값을 저장합니다. 호환 도구가 기존 세션을 사용할 때만 필요합니다.
